# 智耕云枢 — 智慧农业 3D 数据可视化大屏

## 项目概述

面向现代农业管理的 3D 数据可视化大屏，将分散的农业生产数据以三维地图、热力图、图表联动等形式实时呈现，帮助管理者一屏统览生产态势、快速决策。

## 业务背景

校企合作毕业实习项目。传统农业管理平台数据分散在各业务子系统中，管理者缺乏统一的可视化入口，难以快速获取全局信息。本项目通过 3D 大屏整合设备状态、任务进度、气象数据和 AI 问答，实现「一屏统览、辅助决策」。

## 核心功能

| 模块 | 说明 |
|------|------|
| 3D 农业地图 | 省份地形 + 热力图 + 3D 柱状图 + 云层动画，多维度展示区域农业数据 |
| 设备管理 | 设备状态实时监控、运维记录、故障告警 |
| 任务管理 | 任务分配、进度跟踪、工单流转 |
| AI 助手 | 流式问答（SSE 逐字输出），农业知识咨询 |
| 数据大屏 | 产量、气象、土壤、虫害等多维度图表联动展示 |

## 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | React 19 + TypeScript |
| 构建 | Vite |
| 3D 渲染 | Three.js + @react-three/fiber + @react-three/drei |
| 地图 | D3-geo + 热力图 |
| 图表 | ECharts + Recharts |
| 动画 | GSAP |
| 状态管理 | Zustand 5 |
| 样式 | Tailwind CSS 4 + styled-components |
| 请求 | Axios |

## 个人职责

**独立负责前端全部开发**（团队其余成员负责后端与硬件），包括：

- 3D 地图场景搭建：地形渲染、热力图叠加、3D 柱状图、云层动画
- 22 个业务组件开发，对接 91 个后端接口
- 3D 场景与图表面板的双向数据联动
- 首屏加载与 3D 渲染性能优化
- Mock 数据层设计，支持真实后端 / Mock 数据源无缝切换

## 技术亮点

**3D 渲染优化** — 合并几何体 + 场景实例复用，降低 Draw Call，核显帧率从 15fps 提升到 45fps

**首屏性能优化** — 路由懒加载 + 资源预加载，首屏从 4.2s 优化到 1.8s

**数据联动** — 点击 3D 地图区域自动联动图表面板筛选，图表交互反向高亮地图区域

**Mock 架构** — 82 个 RESTful 端点的路由表分发 + SSE 流式 Mock，前端可脱离后端独立开发与演示

## 运行方式

```bash
npm install
npm run dev    # 开发服务器，默认 5173 端口
npm run build  # 构建生产版本
```

## 项目结构

```
src/
├── components/        # 通用组件（图表、动画、虚拟滚动等）
├── core/              # 核心业务组件（设备表、工单、仪表盘等）
├── features/          # 功能模块
│   ├── sc-datav/      # 3D 数据可视化（地图、热力图、柱状图）
│   ├── sysadmin/      # 系统管理（告警、图片上传）
│   └── auth/          # 登录注册
├── hooks/             # 自定义 Hooks（动画帧、防抖、尺寸监听）
├── layouts/           # 布局（侧边栏、个人中心）
├── mock/              # Mock 数据层
├── services/          # API 封装
└── utils/             # 工具函数
```
